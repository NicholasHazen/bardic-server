# History

Bardic v1 was a Python prototype (`NicholasHazen/bardic`, a FastAPI server with a plain JavaScript client). Its analysis, casting and performance features are deferred here; the lessons that matter are folded into the product spec (immutable text and code point offsets, unknown cost is not zero, completed work is kept, plans and limits before spending, content refused by a provider).

The v1 design and API notes that led to v2 are on branch `claude/sharp-cannon-45z552` of that repository: `docs/ux/FOUNDATIONS.md` (v1 nouns, verbs and flows) and `docs/ux/API-PROPOSAL.md`. They are history, not requirements. Where they disagree with `docs/PRODUCT-SPEC.md`, the spec wins.
